# Boruto.XrmService

This project is a migration of Kipon.XrmService. Most of the library has same facade, except for the root namespace.
Boruto.XrmService only support Microsoft Dynamics 365 Dataverse Online (CE).

## install

```bash
npm install boruto-xrmservice
```
